# Results

This directory contains selected evidence from the completed analysis of public sequencing accession ERR14666789.

## Key results

- Total reads: 12,464,796
- Mapped reads: 12,354,224
- Mapping rate: 99.11%
- Raw variant candidates: 735,133
- Filtered variant candidates: 69,052

## Included evidence

The repository retains selected:

- FastQC reports
- alignment statistics
- coverage statistics
- samtools statistics
- bcftools statistics
- variant counts
- run metadata
- pipeline logs

Large FASTQ files, reference genomes, BAM files, and complete VCF files are intentionally excluded from GitHub.
